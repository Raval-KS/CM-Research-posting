# Survey Methodology & Engagement Audit - Debrief Protocol

## Overview
This repository hosts the post-submission debriefing interface for a Department of Community Medicine research initiative conducted at GCS Medical College. 

While the primary survey instrument collects baseline data on undergraduate medical student well-being (utilizing the Perceived Stress Scale), the broader meta-analytical objective of this study is to empirically evaluate the reliability of data collected via unsupervised, asynchronous online questionnaires. Specifically, this project quantifies the prevalence of Insufficient Effort Responding (IER) and heuristic satisficing within medical student convenience samples.

## Repository Contents
* `index.html`: A static, single-page HTML/CSS application that serves as the immediate post-survey debriefing document. 

## Deployment & Integration
This interface is deployed via **GitHub Pages** to ensure high availability and a stable, academic URL structure. It is directly integrated with **KoboToolbox** using the custom Return URL function. 

Upon successful submission of the primary survey, participants are automatically redirected to this debrief page. The page fulfills the Institutional Ethics Committee (IEC) requirements for partial disclosure studies by:
1. Clarifying the dual-purpose nature of the methodology.
2. Explaining the use of embedded validation checkpoints (Instructional Manipulation Checks) and session telemetry (completion latencies).
3. Providing clear instructions for retroactive data withdrawal while maintaining complete participant anonymity.
4. Supplying relevant mental health support resources.

## Methodology Context
Undergraduate medical research frequently relies on unmonitored digital surveys, leading to high risks of survey fatigue and compromised data fidelity. This study functions as an evidence-based audit of peer-led methodologies to determine if the data typically collected in such environments is statistically robust. The findings will be used to formulate evidence-based guidelines for improving the rigor of future questionnaire-based research.
